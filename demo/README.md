# Weak Singular Volterra Demo

`weak_singular_volterra_demo.jl` is a self-contained Julia demo for building
the Chebyshev coefficient matrix of a weakly singular Volterra operator.  It
does not modify or depend on changes to the core `src/` VoltOpt module.

The reusable entry point is:

```julia
A = build_weak_singular_volterra_matrix(K; mu=0.5, N=64, tol=1e-14)
A, info = build_weak_singular_volterra_matrix(K; mu=0.5, N=64, tol=1e-14, return_info=true)
```

Here `N` is the final matrix dimension.  The returned matrix is `N x N` and
already includes the external factor `(1+y)/2`.

Optional keyword arguments include `phi`, `dphi`, `n0`, `nmax`, `max_m`,
`max_n`, `de_h`, `de_tol`, and `Kext_guard`.  The default map is
`phi(x)=x`, `dphi(x)=1`.

## Run The Demo

From the project root:

```bash
julia --project=. demo/weak_singular_volterra_demo.jl
```

Optional examples:

```bash
julia --project=. demo/weak_singular_volterra_demo.jl --mu=0.6 --N=64 --kernel=exp
julia --project=. demo/weak_singular_volterra_demo.jl --kernel=rational --show-matrices
julia --project=. demo/weak_singular_volterra_demo.jl --kernel=constant --N=32 --max-m=64 --max-n=8
```

`--kernel=exp` uses `K(x,t)=exp(-x*t)`. `--kernel=rational` uses
`K(x,t)=1/((x+1)^2+(t-1)^2)`. `--kernel=constant` uses `K(x,t)=1`.

## Algorithm

The current demo follows this route:

```text
stable DE initial moments H_{0,0,k}
+ (j,k) recurrence for the r=0 layer
+ fixed-j (r,k) recurrence for the interior H_{j,r,k}
+ streaming compression over j
+ restriction-operator assembly of G
+ multiplication by M[(1+y)/2]
```

Important details:

- `H_{0,0,k}` is computed in Float64 by the stable double-exponential routine
  in the demo, with log-distance/log-weight endpoint handling, automatic
  truncation, and Neumaier compensated summation.
- The DE path does not evaluate `(1-eta)^(mu-1)` at `eta=1`, and it does not
  keep evaluating transformed nodes that have rounded to the singular endpoint.
- `BigFloat` is not used in the main implementation; it should only be used for
  tests or external reference values.
- The `r=0` layer is generated by the `(j,k)` recurrence from `H_{0,0,k}` with
  guard columns.
- For each fixed `j`, the interior triangular table `H_{j,r,k}` is generated
  independently by the fixed-`j` four-point `(r,k)` recurrence.
- The demo does not store a full `H[j,r,k]` tensor.  It streams each fixed-`j`
  table into `Hcomp[i,r,k] = sum_j C[i,j] H[j,r,k]`.
- `G` is assembled by the restriction-operator formula, with one extra row
  because the final multiplication by `(1+y)/2` needs `G_N`.
- The final returned matrix is `A = M[(1+y)/2] * G`, truncated to `N x N`.

The transformed kernel is

```text
Ktilde_phi(y,eta)
= dphi(tau) * ((phi(y)-phi(tau))/(1-eta))^(mu-1)
  * K(phi(y), phi(tau)),

tau = ((y+1)/2)eta + (y-1)/2.
```

Near `eta=1`, the quotient is replaced by its limit
`((1+y)/2)*dphi(y)`.  For the default identity map, the demo uses the exact
ratio `(1+y)/2` directly.

## Diagnostics

The main script prints:

- `C` dimensions, max coefficient, tail estimate, and sample error.
- Whether `H_{0,0,k}`, `Hcomp`, `G`, and `A` are finite.
- Whether the output matrix is exactly `N x N`.
- Whether the external factor `(1+y)/2` is included.
- DE node counts, endpoint distances, virtual endpoint handling, and the
  convergence table for several `h` values.
- Small `N=32,64` sanity checks unless `--skip-sanity` is passed.

## Constant Kernel PDF Plot

Generate the log-absolute-value heatmap/spy PDF for `K(x,t)=1`, `mu=0.5`, and
matrix size `500 x 500` with:

```bash
julia --project=. demo/plot_logabs_spy_K1_mu0p5.jl
```

The output is:

```text
demo/output/logabs_spy_K1_mu0p5_N500.pdf
```

The plot uses the final matrix `A`, not the intermediate matrix `G`.  Entries
with `abs(A[i,j]) >= 1e-16` are colored by `log10(abs(A[i,j]))`; smaller
entries are left blank.  The plotting script writes only under `demo/output/`
and requires `Plots.jl` to already be available in the active Julia
environment.
